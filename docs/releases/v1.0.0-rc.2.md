# Type3arabi 1.0.0-rc.2 — release candidate · «اكتب عربي» ١.٠.٠ — نسخة مرشّحة للإصدار

Type Arabic on Windows the way you already text. Write Arabizi (`mar7aba`, `3ala`, `2albi`) in any app and
Type3arabi turns it into the Arabic you meant, with the most likely word already picked.

اكتب بالعربيزي في أي برنامج على ويندوز، و«اكتب عربي» يحوّلها إلى العربية التي قصدتها.

## Install
1. Run the MSI. The page after the license lists what it adds. A restart is recommended at the end.
2. Press **Win+Space** and pick Type3arabi, or press **Ctrl+Alt+A** (your own shortcut can be set in Settings).
3. Type `mar7aba` and press Space.

## New since rc.1
- **Stronger Levantine model**: held-out word accuracy 65.1% top-1 / 90.8% top-5 for Levantine (was 61.4% / 87.4%),
  50.4% / 78.9% overall; `oktob` → أكتب and `ahlan` → أهلا again. Two of its datasets are used while their authors'
  permission is pending (see `DATASETS.md`).
- **Password and number fields**: fields an app marks as password, PIN, number, phone, date or amount get plain Latin
  letters and teach it nothing; private/incognito fields never teach it anything.
- **Learning stays fast**: what it learns is compacted automatically, so apps start just as quickly after months of use.
  Two apps learning at the same time no longer miss each other's words.
- **Installer**: never closes your apps and never restarts the PC by itself (also in silent installs, e.g. from the
  Microsoft Store); a page after the license lists what it installs; no console windows flash; version shown in
  Settings › Apps.
- **Settings**: shows when the global shortcut is taken by another program, and offers "Add" when Type3arabi was installed
  from another Windows account.
- Consistent version information on every file ("Type3arabi", 1.0.0-rc.2).

## Known limitations of this candidate
- **Not code-signed yet**: Windows SmartScreen will warn "Unknown publisher". Choose *More info → Run anyway* only if the
  SHA-256 above matches. See the code signing policy: https://type3arabi.com/code-signing
- Upgrading while apps use the keyboard finishes at the next restart (those apps keep the old version until then).
- x64 Windows only (ARM64 later). Egyptian has little training data yet.
