# Type3arabi 1.0.0-rc.3 — release candidate · «اكتب عربي» ١.٠.٠ — نسخة مرشّحة للإصدار

Type Arabic on Windows the way you already text. Write Arabizi (`mar7aba`, `3ala`, `2albi`) in any app and
Type3arabi turns it into the Arabic you meant, with the most likely word already picked.

## New since rc.2
- **The diacritics editor can no longer get stuck.** Typing a letter that is not an editor key (for example you just
  keep typing the next word) now inserts the vowelled word and starts the new one, instead of being swallowed. The
  editor and the suggestion list recover when an app changes or drops the text being typed, and when you click
  elsewhere in the field while typing a word.
- Clicking the popup can no longer leave the mouse unusable in the app.
- The ⚙ tab opens Settings without freezing the app for a moment.
- **Shortcuts Windows or your apps already use are refused**, with the reason (e.g. "used by Windows to copy
  (Ctrl+C)", Win+Shift+S, Alt+Tab). A reserved global shortcut saved earlier is not activated; Settings says why.
- The "Shift (tap)" Arabic/Latin toggle offered in Settings now works.

## Known limitations of this candidate
- **Not code-signed yet**: Windows SmartScreen will warn "Unknown publisher". Choose *More info → Run anyway* only if the
  SHA-256 above matches. Code signing policy: https://type3arabi.com/code-signing
- Upgrading while apps use the keyboard finishes at the next restart.
- x64 Windows only (ARM64 later). Egyptian has little training data yet.
