Type Arabic on Windows the way you already text. Write Arabizi (`mar7aba`, `3ala`, `2albi`) in any app and
Type3arabi turns it into the Arabic you meant, with the most likely word already picked.

اكتب بالعربيزي في أي برنامج على ويندوز، و«اكتب عربي» يحوّلها إلى العربية التي قصدتها.

## Install
1. Run the MSI. It adds **Arabic · Type3arabi** to your Windows languages; a restart is recommended.
2. Press **Win+Space** and pick Type3arabi, or press **Ctrl+Alt+A** (your own shortcut can be set in Settings).
3. Type `mar7aba` and press Space.

## What's in it
- A real Windows keyboard (TSF), one entry under Arabic. Works in every app.
- Candidate list with the best guess preselected; ↓ / click / mouse wheel for the others; Shift+Space keeps the
  Latin word; Backspace right after a word reopens it.
- Automatic dialect: Levantine, Egyptian, Gulf, Iraqi, Maghrebi and MSA, no setting needed.
- Automatic details: «اللّه», «شكراً», Arabic punctuation ، ؛ ؟.
- Tashkeel editor (Tab): any mark on any letter, several letters at once, ready-made vowellings.
- Learns your choices, on this PC only; export/import them to another PC (`.t3learn`), or erase them.
- Settings app: every shortcut editable; light/dark; new brand look. Open it from the small ⚙ tab at the top of
  the suggestion list, the Start menu, or the desktop shortcut.
- Arabic (101) no longer reappears next to Type3arabi after a restart.
- 100% offline: no account, no network, no telemetry. Password fields are left alone.

## Known limitations of this candidate
- **Not code-signed yet** (Owner decision O2 pending): Windows SmartScreen will warn "Unknown publisher".
  Choose *More info → Run anyway* only if the SHA-256 above matches.
- **Model accuracy:** this build ships the release-mode model (approved data only). Held-out word accuracy is
  47.9% top-1 / 75.7% top-5 overall (Levantine 61.4% / 87.4%, Maghrebi 44.8% / 73.1%); the
  data sets still awaiting license clearance make Levantine better (65.1%), see STATUS.md D25. Known misses:
  `oktob` → وكتب, `ahlan` → الا (both correct one ↓ away). Egyptian has little training data yet.
- x64 Windows only (ARM64 later).
- Other Windows accounts on the same PC add the keyboard through Windows language settings.
